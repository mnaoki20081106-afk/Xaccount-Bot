# 仕入れbot 管理画面の使い方

## 普段の操作

1. 「運用状況」で残高と停止原因を確認します。仕入れ先へのLTC入金は、画面の入金先リンクから確認してください。
2. 「仕入れ設定」で予算割合、在庫目標、単価上限を入力し、「仕入れ設定を保存」を押します。
3. 「販売設定」で販売所を選び、販売画面の商品を選んで価格を変更します。「変更を保存して反映」で案内文と商品をまとめて保存します。
「販売設定」の「パネルの色」で左端のライン色を選べます。選ぶとプレビューに反映され、「変更を保存して反映」で色を保存し、設置済みのパネルも更新します。既存の販売所は緑色を引き継ぎます。色設定を保存するにはDiscord-Shiireを最新版に更新・再起動してください。旧バージョンでは色選択を無効にし、更新が必要な旨を表示します。

4. 未設置のチャンネルには「Discordへの設置」から販売画面を設置します。設置済みの画面は保存時に更新されます。
5. 自動仕入れの開始・一時停止は「運用状況」で行います。テスト運転から本番へ切り替える場合は確認が表示されます。

## 画面の役割

| メニュー | 内容 |
| --- | --- |
| 運用状況 | 残高、在庫、運転状態、開始・停止 |
| 仕入れ設定 | 普段の仕入れ条件を一画面で設定 |
| 販売設定 | 販売価格、案内文、Discordへの設置 |
| 履歴と問題 | 仕入れ注文、エラーによる停止、接続状態、操作記録 |

「通常は変更不要の設定」には、詳しい購入条件、資金の補充方法、招待特典、在庫内訳を置いています。入荷通知、定時を待たない購入、予算の再適用も折りたたみを開いた場合だけ表示します。

## 仕入れ設定の注意点

- 予算割合は整数で合計100%。変更した場合のみ、現在残高を再配分します。在庫目標や単価だけの変更で予算を再配分しません。
- 在庫目標は0〜10000個。通常在庫は毎日18:00（日本時間）に不足分を購入します。自動仕入れの停止や安全装置、予算・品質条件の制限は引き続き適用されます。
- 単価上限は、シャドウバンなしが0.50〜0.60 USD、検索上位が1円以上の整数です。既存のサーバー側の制限に合わせています。
- 入荷通知は実際に在庫が増えた場合だけ送ります。通知文は1〜2000文字です。
- 保存は変更した項目だけ送信します。途中で失敗した場合は保存済みの項目名を表示し、入力を残します。再試行では成功した項目を再送しません。複数APIにまたがるため、保存全体は単一のトランザクションではありません。

## 表示名と内部の区分

| 表示名 | 内部区分 |
| --- | --- |
| シャドウバンなし | NO_SHADOWBAN |
| 検索上位 | TOP_SEARCH |
| 招待特典用 | INVITE_CAMPAIGN |

既存の購入判定・在庫区分・販売商品名・販売価格は変更していません。再設置や削除は通常の保存と分離し、「設置済みメッセージの修復」や「販売所を追加・削除」から行います。

## 検証

Reactを実際に描画する操作テストで、4つのメニュー、入力検証、在庫だけを変更した場合の予算維持、保存途中の失敗と再試行、購入履歴、商品の個別編集、複数商品と案内文の一括保存、削除確認を検証します。実ブラウザーからローカルプレビューへの接続は、この実行環境ではブロックされました。
